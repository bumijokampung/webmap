# Webmap/Peta Online Kampung Bumijo Kelurahan Bumijo Kemantren Jetis Kota Yogyakarta

Proyek ini berisikan peta interaktif yang memuat berbagai data seperti batas RTRW, Bangunan, Tutupan Lahan, UMKM, Bank Sampah, Titik Sampah Liar, Fasilitas Umum, Jaringan Jalan. WebGIS ini menampilkan informasi lokasi, jenis usaha, serta data tambahan sebagai bahan analisis.
